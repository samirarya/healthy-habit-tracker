# 21-Day Healthy Habit Accountability App

A modern Next.js accountability application designed to track 21 continuous days of healthy habits across 18 daily dimensions (Morning, Breakfast & Midday, Afternoon, Evening, and Night routines).

## Features

- **21-Day Streak & Challenge Tracker**: Master your daily routine with consecutive day tracking. Missing a day resets your streak.
- **18 Habit Dimensions**: Covers everything from morning hydration, sunlight exposure, and mindfulness to afternoon walks, balanced nutrition, and fixed-bedtime sleep.
- **Interactive Checklist**: Beautiful daily tab navigation, progress bars, celebration animations, and LocalStorage persistence.
- **Accountability Rules**: Strict streak management designed to build lasting habit formation.

## Tech Stack

- **Framework**: Next.js (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
